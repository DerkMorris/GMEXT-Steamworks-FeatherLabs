Dedicated servers

The steam_game_server_* API wraps Steam's game-server pipe. It does not require a signed-in desktop Steam user and is separate from the client steam_* lifecycle. Call steam_game_server_update() every Step (or call the regular steam_update(), which pumps both active pipes).

Minimal public server

// Create event
if (!steam_game_server_init(
    0, 27015, 27016,
    steam_game_server_mode_authentication_and_secure,
    "1.0.0.0"))
{
    show_error("Steam game-server initialization failed", true);
}

// These four fields must be set before LogOn.
steam_game_server_set_product("480"); // Usually your Steam App ID as text
steam_game_server_set_game_description("My Game");
steam_game_server_set_mod_dir("mygame");
steam_game_server_set_dedicated(true);

steam_game_server_set_server_name("My dedicated server");
steam_game_server_set_map_name("arena_01");
steam_game_server_set_max_player_count(16);
steam_game_server_set_password_protected(false);
steam_game_server_set_game_tags("dedicated,ranked");
steam_game_server_set_region("");
steam_game_server_set_advertise_server_active(true);

// Use steam_game_server_log_on(gslt) for a persistent server identity.
steam_game_server_log_on_anonymous();

// Step event
steam_game_server_update();

// Clean Up event
steam_game_server_log_off();
steam_game_server_shutdown();

Player authentication

A client obtains a session ticket and sends its exact bytes, length, and Steam ID over the game's connection. The server passes them to steam_game_server_begin_auth_session(buffer, size, steam_id). Admission is complete only after the Steam Async event steam_game_server_validate_auth_ticket_response reports auth_session_response == 0. Always call steam_game_server_end_auth_session(steam_id) when that player leaves.

Networking and server browser

Existing steam_net_sockets_* and steam_net_messages_* functions automatically use the game-server interface while it is active. Their connection/session callbacks are also registered on both Steam pipes.

Normally Steam owns the query port. To share one UDP socket with gameplay, initialize with steam_game_server_query_port_shared, forward incoming query packets to steam_game_server_handle_incoming_packet(), then drain steam_game_server_get_next_outgoing_packet() every frame and send each returned packet to its ip/port.

Server-authoritative stats

Request a player's data with steam_game_server_stats_request_user_stats(), wait for steam_game_server_stats_received, then use the get/set functions and finish with steam_game_server_stats_store_user_stats(). Steam only permits writes from official game servers whose IP ranges and stat permissions are configured in Steamworks.

Deployment notes

  • The App ID must be available through Steam launch environment or steam_appid.txt during local testing.
  • A GSLT is a secret. Supply it through a protected command-line/configuration channel; never compile it into the game.
  • Open the gameplay and query UDP ports in the host firewall/NAT.
  • Set required product fields before login and enable advertising only after all browser fields are ready.

steam_game_server_init

Initializes the independent Steam game-server API. ip is an IPv4 address in host byte order; use 0 to bind automatically. game_port is the UDP gameplay port. query_port is the Steam server-browser port, or steam_game_server_query_port_shared when queries share the gameplay socket. server_mode selects no authentication, authentication, or authentication plus VAC. version should use the x.x.x.x form and must match the current version configured in Steamworks. Returns true on successful initialization.


Syntax:

steam_game_server_init(ip, game_port, query_port, server_mode, version)
ArgumentTypeDescription
ip Int64 IPv4 in host byte order, normally 0.
game_port Real gameplay UDP port, 0–65535.
query_port Real query UDP port, 0–65535, or steam_game_server_query_port_shared.
server_mode Real a SteamGameServerMode constant.
version String server version in x.x.x.x form.


Returns:

Bool: initialization succeeded.


Example:

var _result = steam_game_server_init(0, 27015, 27016, steam_game_server_mode_authentication_and_secure, "1.0.0.0");

steam_game_server_begin_auth_session

Begins validating a player's ticket. buffer contains the exact bytes received from that player, ticket_size is their length, and steam_id is the claimed identity. Returns a steam_game_server_begin_auth_* value for immediate validation. An immediate OK is not final admission: wait for steam_game_server_validate_auth_ticket_response.

This function operates asynchronously. Its final result is delivered through the Steam Async Event.


Syntax:

steam_game_server_begin_auth_session(buffer, ticket_size, steam_id)
ArgumentTypeDescription
buffer Real buffer containing ticket bytes.
ticket_size Real number of valid bytes.
steam_id Int64 claimed player Steam ID.


Returns:

Real: a steam_game_server_begin_auth_* value.


Triggers:

Steam Async Event

KeyTypeDescription
event_type String The string value "steam_game_server_validate_auth_ticket_response".
steam_id Int64 The player whose ticket was validated.
owner_steam_id Int64 The license owner's Steam ID; differs for borrowed copies.
auth_session_response Real A steam_game_server_auth_response_* value.


Example:

var _result = steam_game_server_begin_auth_session(auth_buffer, ticket_size, player_steam_id);

SteamGameServerMode

These constants select the Steam backend policy passed as the server_mode argument to steam_game_server_init. The mode must be chosen during initialization and cannot be changed without shutting down and initializing the game-server API again.

Note

This setting controls Steam authentication, master-server eligibility, and VAC policy. It does not create the gameplay transport: GameMaker sockets or SteamNetworkingSockets must still be initialized separately.

These constants are referenced by the following function:

  • steam_game_server_init


MemberValueDescription
steam_game_server_mode_no_authentication 1 Disables Steam user authentication. The server is not VAC-secured and is not listed on the Steam master server. Use this for LAN, private testing, or discovery handled entirely by your own backend.
steam_game_server_mode_authentication 2 Enables Steam user authentication and master-server listing, but does not request VAC protection. Player tickets can be validated with steam_game_server_begin_auth_session.
steam_game_server_mode_authentication_and_secure 3 Enables Steam user authentication, master-server listing, and VAC protection. Check the steam_game_server_policy_response event or steam_game_server_secure before presenting the server as secure.


Example:

var _ok = steam_game_server_init(
    0,
    27015,
    27016,
    steam_game_server_mode_authentication_and_secure,
    "1.0.0.0"
);

The example initializes a public Steam-authenticated dedicated server that requests VAC protection.
