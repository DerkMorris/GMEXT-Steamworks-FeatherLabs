network_get_local_ipv4_addresses

This function enumerates IPv4 addresses assigned to local network adapters. It does not require Steam to be initialized and may return Ethernet, Wi-Fi, VPN, virtual, disconnected, and loopback interfaces.

Note

A computer can have several valid local addresses. The function deliberately returns every address instead of guessing which adapter should be used by a server.


Syntax:

network_get_local_ipv4_addresses()


Returns:

Array of Structs

MemberTypeDescription
addressStringIPv4 address in dotted notation, for example 192.168.1.20.
adapter_nameStringFriendly adapter name on Windows, or the interface name on Linux/macOS.
prefix_lengthRealNetwork prefix length, for example 24 for the mask 255.255.255.0.
is_upBooleanWhether the operating system reports the adapter as operational.
is_loopbackBooleanWhether the address belongs to a loopback interface such as 127.0.0.1.


Example:

var _interfaces = network_get_local_ipv4_addresses();

for (var _i = 0; _i < array_length(_interfaces); ++_i)
{
    var _interface = _interfaces[_i];

    if (_interface.is_up && !_interface.is_loopback)
    {
        show_debug_message(
            _interface.adapter_name + ": " + _interface.address
        );
    }
}

The example prints every active non-loopback IPv4 address. VPN and virtual adapters are intentionally not filtered automatically.

network_ipv4_to_number

This function converts an IPv4 address in dotted notation to the numeric host-order representation expected by steam_game_server_init. It does not perform DNS resolution and does not require Steam to be initialized.


Syntax:

network_ipv4_to_number(ip)
ArgumentTypeDescription
ipStringIPv4 address containing four decimal octets, for example "192.168.1.20".


Returns:

Int64

The numeric IPv4 address in host byte order. Returns -1 if the string is not a valid IPv4 address. Valid results range from 0 through 4294967295.


Example:

var _ip = network_ipv4_to_number("192.168.1.20");

if (_ip == -1)
{
    show_error("Invalid server IP address", true);
}

steam_game_server_init(
    _ip,
    27015,
    27016,
    steam_game_server_mode_authentication,
    "1.0.0.0"
);

network_ipv4_to_number("127.0.0.1") returns 2130706433 (0x7F000001). Use 0 directly when the server should bind to all local IPv4 interfaces.

Dedicated-server console

The console functions provide interactive text input and output for a dedicated server. On Windows, console_open allocates a console for the current game process without launching cmd.exe. On Linux and macOS, the functions use the terminal or standard streams from which the server was launched.

Note

Console input is non-blocking. Call console_read_line regularly from a Step event; it immediately returns an empty string when no complete command is waiting.

Tip

Use console_log for server messages that should be visible both in the GameMaker IDE Output window and in the server console.

console_open

Opens the interactive console used by the current game process. Calling this function when the console is already open keeps the existing console and updates its title.


Syntax:

console_open(title)
ArgumentTypeDescription
titleStringTitle shown by the console window or terminal.


Returns:

Boolean: true if console input/output is available.


Example:

if (console_open("My Game Dedicated Server"))
{
    console_log("Server console ready");
}

console_log

ArgumentTypeDescription
textStringText to write to both destinations.

console_clear

Clears the console display and moves the cursor to the top-left corner without discarding commands already waiting for console_read_line. On Windows, a visible prompt and its current editable command are redrawn after the clear operation. Normally this function is called in response to a completed clear command, when no command is being edited.


Syntax:

console_clear()


Returns:

Boolean: whether the console display was cleared.


Example:

if (_command == "clear")
{
    console_clear();
}

console_set_prompt

Changes the immutable prefix displayed before the editable command text. The default prompt is > . The prompt is visual only and is never included in the string returned by console_read_line.


Syntax:

console_set_prompt(prompt)
ArgumentTypeDescription
promptStringPrefix such as "> " or "server> ". An empty string disables the visible prefix.


Returns:

Boolean: whether the prompt value was accepted.


Example:

console_set_prompt("server> ");

If the console displays server> status, pressing Enter causes console_read_line() to return only "status". Backspace can erase status, but not server> .

console_read_line

Removes and returns the oldest complete command entered in the console. The function never waits for input, so it is safe to call every frame. While it is called regularly, the console displays the immutable prompt and the editable command text. The returned string contains only the command, without the prompt or line ending.


Syntax:

console_read_line()


Returns:

String: the command without its line ending, or "" when no command is waiting. Empty commands are ignored.


Example:

// Step Event
var _command = console_read_line();

while (_command != "")
{
    switch (string_lower(_command))
    {
        case "status":
            console_log("Players online: " + string(instance_number(obj_player)));
            break;

        case "quit":
            console_log("Shutting down");
            game_end();
            break;

        default:
            console_log("Unknown command: " + _command);
            break;
    }

    _command = console_read_line();
}

The loop drains every command already waiting in the console during the current step.

console_close

Stops console input/output and clears queued commands. On Windows, a console allocated by console_open is detached and closed. An inherited terminal on Linux or macOS is not destroyed or reconfigured.


Syntax:

console_close()


Returns:

Boolean: true if a console was open.


Example:

// Clean Up Event
console_close();
